VPC Layout

  VPC CIDR: 10.0.0.0/16

  Use 2 Availability Zones (required by ALB, and good practice for RDS Multi-AZ):

  ┌──────────────────┬────────────┬─────────────┬──────────────────────────────────┐
  │      Subnet      │     AZ     │    CIDR     │             Contains             │
  ├──────────────────┼────────────┼─────────────┼──────────────────────────────────┤
  │ Public Subnet A  │ us-east-1a │ 10.0.1.0/24 │ ALB, Internet Gateway attachment │
  ├──────────────────┼────────────┼─────────────┼──────────────────────────────────┤
  │ Public Subnet B  │ us-east-1b │ 10.0.2.0/24 │ ALB (second AZ), NAT Gateway     │
  ├──────────────────┼────────────┼─────────────┼──────────────────────────────────┤
  │ Private Subnet A │ us-east-1a │ 10.0.3.0/24 │ ECS Fargate tasks                │
  ├──────────────────┼────────────┼─────────────┼──────────────────────────────────┤
  │ Private Subnet B │ us-east-1b │ 10.0.4.0/24 │ ECS Fargate tasks                │
  ├──────────────────┼────────────┼─────────────┼──────────────────────────────────┤
  │ DB Subnet A      │ us-east-1a │ 10.0.5.0/24 │ RDS PostgreSQL                   │
  ├──────────────────┼────────────┼─────────────┼──────────────────────────────────┤
  │ DB Subnet B      │ us-east-1b │ 10.0.6.0/24 │ ElastiCache Redis                │
  └──────────────────┴────────────┴─────────────┴──────────────────────────────────┘

  NAT Gateway lives in a public subnet but serves the private subnets — a common point of confusion when drawing.

  draw.io Setup Tips

  1. Open https://diagrams.net → Extras → Edit Diagram to paste XML, or use the drag-and-drop AWS shape library
  2. Enable AWS shapes: View → Shapes → AWS (search "AWS19" for the current icon set)
  3. Use swimlane containers for VPC, then nested containers for each subnet
  4. Color convention: blue = public, orange/yellow = private app tier, red = private DB tier — matches AWS documentation style
